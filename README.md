# echo-aide.github.io

Сайт застосунку «Ехо» для GitHub Pages. Статичний HTML/CSS без збірки.

## Локальний перегляд

```bash
python -m http.server 8000
```

Відкрийте http://localhost:8000.

## Публікація

Репозиторій `echo-aide.github.io` має бути публічним і належати акаунту або організації `echo-aide`. Settings → Pages → Deploy from a branch → `main` / `(root)`.

Інсталятори викладайте в Releases цього репозиторію: код застосунку приватний, його релізи недоступні публічно.
